# Уведомления об акциях «Зелёные ценники» Вкусвилл

Скрипт для Chrome, который следит за акционными товарами («Зелёные ценники») Вкусвилла
и присылает уведомления в личные сообщения ВКонтакте.

Работает как Chrome Snippet: запускается прямо на странице Вкусвилла, без установки расширений и Node.js.

## Что понадобится

- Браузер Chrome (или другой на Chromium).
- Аккаунт Вкусвилл.
- Аккаунт ВК и небольшое сообщество ВК для отправки уведомлений.

## Настройка ВК

1. Зайди в ВК и посмотри свой **id** (например, в адресе страницы: `vk.com/id123456789`).
2. Открой раздел **Сообщества** и создай новое сообщество.
3. При желании в настройках сообщества сделай его **частным** (закрытым).
4. Создай для сообщества **API-токен** с правами на отправку сообщений.
5. Напиши в чат сообщества первое сообщение — без него отправка не сработает.

## Запуск скрипта

1. Войди на сайт Вкусвилл и авторизуйся.
2. Открой любую страницу Вкусвилла под своим аккаунтом — например, добавь товар в корзину
   и перейди на страницу **корзины**. Список акционных товаров скрипт берёт не из корзины,
   а из отдельного запроса к сайту; корзина нужна только чтобы открыть страницу с рабочей сессией.
3. Открой DevTools (`F12`) → вкладка **Sources** → **Snippets**.
4. Создай новый сниппет и вставь в него скрипт.
5. Настрой скрипт под себя: как минимум укажи **VK userId** и **VK-токен** (из шага «Настройка ВК»).
   В скрипте на их месте стоят заглушки `12345678` и `'token'` — их нужно заменить.
   Остальное настраивается по желанию (см. «Настройки скрипта»).
6. Запусти сниппет: `Ctrl+Enter` или кнопка запуска внизу панели.
   При первом запуске скрипт сразу пришлёт в ВК текущий список акционных товаров
   (или сообщение, что ценников сейчас нет).
7. Окна DevTools можно свернуть — скрипт продолжит работу.

## Важно

- Вкладку с Вкусвиллом **не закрывай и не перезагружай**: скрипт живёт внутри страницы, и при
  перезагрузке его нужно запустить заново.
- **Не уводи вкладку в фон и не минимизируй окно браузера.** Chrome притормаживает таймеры в
  неактивных вкладках, и реальный интервал проверки может сильно вырасти.
- Остановить мониторинг можно из консоли: `stopGreenLabelsMonitor()`. Повторный запуск скрипта
  без остановки игнорируется — в консоли появится предупреждение.
- Если после первого запуска проверка сломается, в ВК придёт сообщение с текстом ошибки (⚠️).
- **Ошибки отправки в ВК не видны.** Запрос уходит в режиме `no-cors`, поэтому скрипт всегда пишет
  «запрос отправлен», даже если ВК его отклонил. Если уведомления не приходят — проверь токен,
  id и что первое сообщение в чат сообщества действительно отправлено.

## Настройки скрипта

Все настройки собраны в одном блоке в начале скрипта и подписаны комментариями.
Обязательно заполнить только id и токен — остальное можно подкрутить под себя.

**Обязательные**

| Параметр | Описание |
| --- | --- |
| VK userId | Твой числовой id ВК, куда приходят уведомления |
| VK-токен | API-токен сообщества с правами на сообщения |

**По желанию**

| Настройка | Описание |
| --- | --- |
| Интервал проверки (`BASE_INTERVAL_SECONDS`) | Период проверки **в секундах**, по умолчанию `130` (около 2 минут). К интервалу добавляется случайный разброс ±25%, но не меньше 20 секунд — точное время каждый раз немного отличается. Меньше интервал — быстрее узнаешь об акции, но больше запросов к сайту. |
| Товары, пропавшие из акции (`SEND_REMOVED`) | Присылать ли отдельное уведомление, когда товар перестал быть акционным. По умолчанию `false` — такие товары только пишутся в консоль. |
| Интересные товары (`INTERESTING`) | Список названий, которые тебе важны. Поиск идёт по вхождению без учёта регистра, поэтому достаточно части названия: `'манго'` поймает все товары с манго. Найденные в акции интересные товары помечаются ⭐ в уведомлении. |

Других настроек пока нет — всё остальное работает автоматически.
